# Reference provenance

The numerical values and profile fits used by this tutorial are transcribed in
`data/reference-models.json` from:

M. Xiao, A. Ceci, P. Orlandi and S. Pirozzoli, “Direct numerical simulation of
drag reduction in rotating pipe flow up to Re_tau approximately 3000”, Journal
of Fluid Mechanics 996 (2024), A24,
<https://doi.org/10.1017/jfm.2024.811>.

The article is distributed under CC BY 4.0.  No raw DNS field or profile file is
redistributed here.  The project-authored mesh and analysis scripts are GPL-3.0-or-later.
