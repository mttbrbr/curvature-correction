# Generated validation data

This directory is intentionally empty in Git. Validation inputs may reproduce
or interpolate external reference series, so they remain on the private runner.
Reviewed aggregate reports are versioned under `reports/curvature-validation/`.

Legacy TMR inputs can still be fetched with `tools/fetch_benchmark_data.py`.
Physical v1.0 campaigns use the mounted archive contract documented in
`docs/validation-protocol.md`. Source licences and checksums are recorded in
`data/benchmark-sources.json` and in each campaign manifest.
